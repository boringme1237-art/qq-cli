## 常见安装问题

- **git clone 超时 / TLS 握手失败**：国内网络直连 GitHub 常被阻断，需自行
  解决网络访问（代理或镜像加速），这也是本仓库只发布在 GitHub 的原因。
- **`init` 找不到密钥**：确认 QQ 正在运行且已登录；刚启动的话先打开几个
  聊天会话再试；必要时用管理员权限运行。
- **杀毒软件告警**：工具只调用 `ReadProcessMemory` 做只读扫描，不注入、
  不写入，可放心放行。
